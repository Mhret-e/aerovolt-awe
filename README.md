#  AeroVolt — Airborne Wind Energy Data Logger

An ESP32-based firmware for a **tethered, helium-lifted Airborne Wind Energy (AWE) prototype**.  
The system collects real-time environmental and electrical data during flight, transmits it wirelessly to a ground server, and integrates with a Reinforcement Learning model to autonomously optimize altitude for maximum power output.

---

##  What It Does

- Reads **temperature, humidity, pressure, and altitude** via a BME280 sensor
- Measures **voltage and current** output from an onboard wind turbine generator
- **Calculates power output** and estimated wind speed in real time
- Transmits data to a **local Flask server** over Wi-Fi using HTTP POST
- Syncs with **Arduino IoT Cloud** for live dashboard monitoring
- Controls a **relay** to manage battery charging (stops at 12V max)
- Supports a **motor control** interface for tether-based altitude adjustment

---

##  Hardware Requirements

| Component | Purpose |
|---|---|
| ESP32 | Main microcontroller (Wi-Fi + data processing) |
| BME280 | Temperature, humidity, pressure, altitude |
| Voltage Sensor (pin 34) | Turbine output voltage measurement |
| Current Sensor ACS712-5A (pin 35) | Turbine output current measurement |
| Voltage Divider (pin 32) | Battery voltage monitoring |
| Relay (pin 26) | Charge/discharge control |
| DC Motor (pins 4, 5) | Tether reel for altitude control |
| LED (pin 2) | Status indicator |
| 12V Battery | Energy storage |

## Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/Mhret-e/aerovolt-awe.git
cd aerovolt-awe
```

### 2. Configure your credentials

Open `sketch_may11a.ino` and replace the placeholders:

```cpp
const char* ssid     = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";
```

Also update the server URL to match your local machine's IP:

```cpp
const char* url = "http://YOUR_LOCAL_IP:5000/data";
```

### 3. Set up `thingProperties.h`

This file is auto-generated by **Arduino IoT Cloud**. Create your own Thing at [create.arduino.cc](https://create.arduino.cc) and download the file. It should define at minimum:

```cpp
float temperature, humidity, altitude, voltage, current;
bool motor, led;
```

>  **Do not commit `thingProperties.h`** — it contains your device secret. Add it to `.gitignore`.

### 4. Install Arduino Libraries

Install via the Arduino Library Manager:

- `Adafruit BME280 Library`
- `Adafruit Unified Sensor`
- `ArduinoIoTCloud`
- `Arduino_ConnectionHandler`

### 5. Upload

Select **ESP32 Dev Module** as your board and upload via the Arduino IDE.

## Data Endpoints

The firmware sends HTTP POST requests to three endpoints on a local Flask server:

| Endpoint | Data Sent |
|---|---|
| `/data` | temperature, humidity, wind speed, altitude, voltage, current |
| `/data` (duplicate) | same as above (second send for redundancy) |
| `/processed` | wind speed, altitude, power change (for RL model input) |

## Known Limitations

- The local server URL (`192.168.x.x`) only works on the same network — replace it with your own IP before use
- Wind speed is estimated from voltage using an empirical formula (`windspeed = V^(1/3) × 4.82`) — not from a direct anemometer reading in this code
- Battery charging logic is basic threshold-based (relay cuts off at 12V)
